# 时间单位换算 · uTools 插件

Vue 3 + Vite 写的 uTools 插件，在 **年 / 月 / 周 / 天 / 时 / 分 / 秒 / 毫秒 / 微秒 / 纳秒** 共 10 个单位之间互相换算。参考 [shijian.bmcx.com](https://shijian.bmcx.com/) 的换算器做的本地实现——换算全部在本地完成，不依赖任何接口，离线可用。

## 功能

- 10 个时间单位，从年到纳秒
- 任意一行填入数值，点「转换」或按回车，其余 9 行立即刷新，并高亮当前的基准行
- 一键「清空」；空值与非法输入给出行内提示，不弹窗
- 结果保留 6 位有效数字，超出常规区间自动改用科学计数法，不会出现一长串的零
- 插件窗口高度自动跟随内容；窗口撑不开时（分离窗口 / 小屏幕）自动切双列布局，尽量不用下拉
- 适配系统深色模式

## 换算口径

内核以**纳秒**为基准、用可精确表示的整数因子，保证 `1 ms ÷ 1 μs = 1000` 这种换算不会出现 `1000.0000000000001` 的浮点误差。

| 单位 | 符号 | 换算 |
| --- | --- | --- |
| 年 | year | 365 天 |
| 月 | month | 30 天 |
| 周 | week | 7 天 |
| 天 | day | 24 时 |
| 时 | hour | 60 分 |
| 分 | minute | 60 秒 |
| 秒 | s | 1000 毫秒 |
| 毫秒 | ms | 1000 微秒 |
| 微秒 | μs | 1000 纳秒 |
| 纳秒 | ns | 基准单位 |

> 按上表口径，1 年 = 365 天 ≈ 12.1667 月，并不等于 12 个月。需要「1 年 = 12 月」的话，改 `src/core/timeUnits.js` 里的单位表即可。

## 使用

在 uTools 输入 `时间换算`、`时间单位换算` 或 `shijianhuansuan` 进入插件：

1. 在任意一行填入数值
2. 点该行「转换」，或直接在该行按回车
3. 想换基准，改另一行的数值再点它自己的「转换」

例如在「天」里输入 `1`：时 24、分 1440、秒 86400、毫秒 86400000、微秒 86400000000、纳秒 8.64e+13。

## 开发

```bash
npm install
npm run dev     # 本地预览 http://localhost:5173
npm test        # Vitest 单测
npm run build   # 构建到 dist/
```

在 uTools 里调试，两种方式二选一：

- **生产构建**：`npm run build` 后，在 uTools 开发者工具里把项目指向 `dist/plugin.json`。改完源码要重新构建，然后退出插件再重新进入（uTools 只在进入时读取文件）。
- **开发模式**：把项目指向 `public/plugin.json`，在 uTools 里开启开发模式，配合 `npm run dev` 走 Vite 热更新，改动即时生效。

## 目录结构

```
assets/icon.svg             图标源文件（渲染成 public/logo.png）
public/plugin.json          uTools 插件清单：功能 code、说明、触发词
src/core/timeUnits.js       换算内核：单位表 / convert / parseInput / formatValue
src/core/pluginWindow.js    插件窗口高度自适应，撑不开时回调切换双列
src/TimeConvert/index.vue   换算界面
src/App.vue                 uTools 进入 / 退出事件与功能路由
```

图标是矢量画的：改 `assets/icon.svg` 后用任意 SVG 导出工具重新导出成 256×256 的
`public/logo.png` 即可（uTools 插件图标要求 PNG、建议 256×256）。

## 测试

`npm test` 覆盖：

- 单位表顺序与最小单位
- 各档换算（时/分/秒、天/周/月/年、毫秒以下的千进制）与反向换算的往返精度
- 未知单位报错
- 数值格式化：6 位有效数字、常规区间与科学计数法边界
- 输入解析：空值、非法字符、小数、正负号、科学计数法
- 插件窗口高度自适应：撑高、按屏幕截断、回退取屏幕高度、撑不开时回调
- 界面能渲染出全部 10 行单位
